# Title :- Fastag Flow Simulation 
## About the project 
This project is a traffic simulation made using p5.js 
It compares FASTag lanes with Manual lanes and shows how traffic congestion changes in both systems. 

The main goal of this project is to show how fastag  saves our time, while manual / cash gate takes more time as compared to fastag.

## Features 
1. Traffic Density slider 
2. Temperature slider (user can control the temperature)
3. Type of lane chnaging when mouse is pressed (Manual-->fastag, fastag-->Manual)
4. VIP convoy special interaction 
5. Horn effects and used emojis to show the emotions 
6. Animated toll barrier 
7. Different vehicles like Car , bus 

## Controls 
1. User can switch lane by clicking on the hordings 
2. Can press S for thr VIP convoy 
3. use the density slider to increase the traffic / congestion  
4. Use the temperature slider to increase the chaos / anger 

## Tech Used 
1. p5.js 
2. javascript 
3. HTML 

## Goal behind this
we wanted to make a traffic simulation based on Indian toll plazas , this project focuses on how fastag improves traffic flow as compared to the normal/cash. we also added emotional ,reactions and sound to make it more realistic .
